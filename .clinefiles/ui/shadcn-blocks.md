## Installation & Usage

### Install a Block

```bash
# General format
npx shadcn@latest add https://ui.shadcn.com/r/styles/default/[block-name].json

# Example: Dashboard block
npx shadcn@latest add https://ui.shadcn.com/r/styles/default/dashboard-01.json
```

### Customize After Installation

All blocks are added to your project and can be fully customized:

1. **Files are added to your project** - Usually in `components/` directory
2. **Modify components directly** - Change styling, behavior, structure
3. **Update imports** - Use the components in your pages
4. **Extend functionality** - Add new features as needed

### Block Dependencies

Many blocks automatically install their required shadcn/ui components. If dependencies are missing:

```bash
# Install missing components manually
npx shadcn@latest add button card input form
```
