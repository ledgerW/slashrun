# shadcn/ui Components Reference

This document provides a comprehensive list of all available shadcn/ui components with installation commands and links to documentation.

**Official Documentation:** [ui.shadcn.com/docs/components](https://ui.shadcn.com/docs/components)

## Installation Tips

1. **Install multiple components at once:**
   ```bash
   npx shadcn@latest add button card dialog input form
   ```

2. **All components are customizable** - They're added to your codebase, not installed as dependencies.

3. **Check for updates:**
   ```bash
   npx shadcn@latest diff
   ```

4. **Browse the full catalog:**
   - Components: [ui.shadcn.com/docs/components](https://ui.shadcn.com/docs/components)
   - Blocks: [ui.shadcn.com/blocks](https://ui.shadcn.com/blocks)
   - Charts: [ui.shadcn.com/charts](https://ui.shadcn.com/charts)
   - Themes: [ui.shadcn.com/themes](https://ui.shadcn.com/themes)
